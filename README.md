# Niksuna's AutoLab Showcase

Build a one-page website for a local car detailing business called "Niksuna's AutoLab", based in Aytos, Bulgaria (обл. Бургас).

BRAND STYLE:

- Dark, garage/automotive aesthetic — black background, red/white accent (matching their logo: a bold shield-style badge with red claw-mark scratches)

- Clean, modern sans-serif typography

- Bold, high-contrast photography-forward design (they have strong car photo/video content)

- Mobile-first — most visitors will view on phone

SECTIONS (in order):

1. HERO

- Business name: "Niksuna's AutoLab"

- Location line: "Аytos, Burgas Region"

- One-line tagline: professional auto detailing — PPF protection, window tinting, interior re-wrapping

- Full-width background image slot (placeholder: dark garage / car close-up)

- Primary CTA button: "Contact Us" (scrolls to contact section)

2. SERVICES

Three service cards, each with icon + title + 1-2 sentence description:

- Interior Re-Wrapping (ceilings, door panels, speaker trim) — "Претапициране на тавани/кори/колонки"

- Window Tinting (auto glass film) — "Фолиране на автостъкла"

- PPF Protection (headlights and paint protection film) — "PPF фарове"

No pricing displayed anywhere on this page.

3. PORTFOLIO / GALLERY

- Photo grid, 6-9 image placeholder slots

- Should support before/after style pairs where possible

- Lightbox/click-to-enlarge on images

4. WHY CHOOSE US (optional short trust section)

- 3 short trust points: experienced work (tagged customer photos on their IG), quality materials, local to Aytos

5. CONTACT

- Contact form: Name, Phone, Message → will connect to EmailJS (placeholder fields for now, note in code comments where EmailJS keys go)

- Phone number and Instagram link (placeholder icons/links, to be filled in)

- Location text: Aytos, Burgas Region

TECHNICAL NOTES:

- Single page, smooth-scroll anchor navigation between sections

- Fully responsive, mobile-first

- Keep load-fast — optimize image placeholders

- No pricing/price list anywhere in the content or code

- Footer: small credit line "Website by Aytos Online" linking to aytos.online
